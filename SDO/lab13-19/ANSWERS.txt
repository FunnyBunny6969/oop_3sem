Контрольные вопросы и ответы

1. Что такое многопоточность? Для чего она используется?
Ответ: Многопоточность — это способность программы выполнять несколько задач одновременно, при этом каждый поток представляет собой независимый путь выполнения внутри процесса. Она используется для выполнения длительных операций в фоновом режиме, чтобы не блокировать основной поток и сохранять отзывчивость приложения, а также для параллельного использования нескольких ядер процессора.

2. Как создать и запустить поток в C#?
Ответ: Нужно создать объект класса Thread, передав ему делегат на метод (напрямую, через ThreadStart или лямбда-выражение), а затем вызвать метод Start. Например: Thread thread = new Thread(SomeMethod); thread.Start();

3. Как передать параметры в поток?
Ответ: Для передачи параметра используется делегат ParameterizedThreadStart: поток создаётся как new Thread(new ParameterizedThreadStart(WorkerMethod)), а значение передаётся в метод Start, после чего внутри метода приводится к нужному типу. Также можно использовать лямбда-выражение, захватывающее переменные, или класс с полями данных.

4. Как дождаться завершения другого потока?
Ответ: С помощью метода Join, который приостанавливает выполнение текущего потока до завершения указанного потока: thread.Join().

5. Что такое приоритет потока? Какие значения он может принимать?
Ответ: Приоритет потока определяет, как часто планировщик выделяет время этому потоку по сравнению с другими потоками. Он задаётся свойством Priority и принимает значения перечисления ThreadPriority: Highest, AboveNormal, Normal (по умолчанию), BelowNormal, Lowest.

6. Что такое состояние гонки (race condition)? Как его избежать?
Ответ: Состояние гонки — это ситуация, когда результат выполнения зависит от порядка выполнения потоков, например при неатомарном изменении общего ресурса. Избежать его позволяет синхронизация доступа к разделяемым данным с помощью lock, Monitor, Mutex, Semaphore и других механизмов.

7. Для чего используется оператор lock?
Ответ: Оператор lock обеспечивает монопольный доступ к разделяемому ресурсу: в критическую секцию в каждый момент времени может войти только один поток, остальные ожидают освобождения блокировки.

8. Чем отличаются фоновые потоки от основных?
Ответ: Процесс завершается только после завершения всех основных (foreground) потоков. Фоновые (background) потоки автоматически завершаются при завершении всех основных потоков, не дожидаясь своей работы. Сделать поток фоновым можно через thread.IsBackground = true.

9. Как принудительно завершить поток? Почему это не рекомендуется?
Ответ: Принудительно поток завершает метод Abort, выбрасывающий исключение ThreadAbortException. Это не рекомендуется, так как поток может быть прерван в произвольный момент, что оставляет ресурсы и данные в несогласованном состоянии; вместо этого рекомендуют использовать флаг для сигнализации потоку о необходимости завершения.

10. Какие проблемы могут возникнуть при использовании нескольких потоков?
Ответ: Основные проблемы — состояние гонки (результат зависит от порядка выполнения потоков), взаимная блокировка (deadlock), когда потоки блокируют друг друга, и инверсия приоритета, когда высокоприоритетный поток ожидает ресурс, занятый низкоприоритетным.
