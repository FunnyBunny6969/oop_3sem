Контрольные вопросы и ответы

1. Что такое исключение? Для чего используется механизм исключений?
Ответ: Исключение — это проблема, возникающая во время выполнения программы. Механизм исключений отделяет код обработки ошибок от основного кода и передаёт информацию об ошибке вверх по стеку вызовов.

2. Какие основные классы исключений существуют в C#?
Ответ: System.Exception — базовый класс для всех исключений, System.SystemException — для системных исключений CLR, System.ApplicationException — для исключений приложений. Часто используются DivideByZeroException, IndexOutOfRangeException, NullReferenceException, ArgumentException, FormatException, OverflowException.

3. Как записывается конструкция try-catch-finally?
Ответ: Блок try содержит код, который может вызвать исключение; за ним идут один или несколько блоков catch для обработки конкретных типов исключений; необязательный блок finally выполняется всегда.

4. Для чего используется блок finally? Всегда ли он выполняется?
Ответ: Блок finally используется для освобождения ресурсов (закрытие файлов, соединений, освобождение памяти). Он выполняется всегда — независимо от того, возникло исключение или нет.

5. Чем отличается catch от finally?
Ответ: Блок catch перехватывает и обрабатывает исключение и выполняется только при его возникновении. Блок finally выполняется всегда и служит для очистки и освобождения ресурсов.

6. Как создать собственное исключение?
Ответ: Нужно унаследовать класс от Exception и реализовать несколько конструкторов (по умолчанию, с сообщением, с сообщением и внутренним исключением), при необходимости добавив собственные свойства для дополнительной информации.

7. Для чего используется оператор throw?
Ответ: Для генерации исключения вручную, например throw new ArgumentException("..."), либо для повторной генерации текущего исключения после частичной обработки с помощью throw;.

8. В чем разница между throw ex и throw?
Ответ: throw ex выбрасывает исключение заново, но сбрасывает стек вызовов начиная с текущего места. throw без аргумента повторно выбрасывает то же исключение с сохранением полной информации о стеке, поэтому его и следует использовать.

9. Что произойдет, если исключение не будет обработано?
Ответ: Если исключение не перехвачено, оно распространяется до конца стека вызовов, и программа аварийно завершается с сообщением об ошибке.

10. Для чего используется оператор using?
Ответ: Оператор using автоматически вызывает Dispose у объекта, реализующего IDisposable, по завершении блока. Это синтаксический сахар для try-finally, обеспечивающий корректное освобождение ресурсов.
