Контрольные вопросы и ответы

1. Что такое наследование? Для чего оно используется?
Ответ: Наследование — это механизм, позволяющий создать новый класс на основе существующего. Производный класс получает члены базового класса и может добавлять свои или изменять унаследованные; используется для повторного использования кода и создания иерархий классов.

2. Как объявить класс-наследник в C#?
Ответ: Указать базовый класс после двоеточия, например: class Dog : Animal { ... }

3. Что такое виртуальные методы? Для чего нужно ключевое слово virtual?
Ответ: Виртуальный метод — это метод базового класса, который может быть переопределён в производном классе. Ключевое слово virtual разрешает такое переопределение.

4. Что такое переопределение методов? Чем оно отличается от скрытия?
Ответ: Переопределение (override) заменяет реализацию виртуального метода и работает полиморфно. Скрытие (new) создаёт новый метод, который не участвует в полиморфизме и вызывается по типу переменной.

5. Для чего используется ключевое слово base?
Ответ: base используется для доступа к членам базового класса из производного, в том числе для вызова конструктора базового класса.

6. Что такое полиморфизм? Как он реализуется в C#?
Ответ: Полиморфизм — это способность объекта принимать множество форм, позволяющая работать с объектами разных классов через общий интерфейс. В C# он реализуется через виртуальные и переопределённые методы, а также через переменные базового класса.

7. Что такое запечатанный класс (sealed)? Для чего он нужен?
Ответ: Запечатанный (sealed) класс — это класс, от которого нельзя наследовать. Он используется, когда нужно запретить дальнейшее наследование.

8. Можно ли в C# наследоваться от нескольких классов одновременно?
Ответ: Нет, в C# поддерживается только одиночное наследование: класс может иметь только одного непосредственного родителя.

9. Как вызвать конструктор базового класса из конструктора производного?
Ответ: Через ключевое слово base в объявлении конструктора, например: public Car(...) : base(...) { ... }

10. Что произойдет, если вызвать виртуальный метод через переменную базового класса?
Ответ: Будет вызвана реализация метода, соответствующая фактическому (динамическому) типу объекта, — это и есть полиморфный вызов.
