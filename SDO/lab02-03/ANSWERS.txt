Контрольные вопросы и ответы

1. Что такое класс? Для чего он используется?
Ответ: Класс — это ссылочный тип данных, который является шаблоном для создания объектов. Он определяет состояние (данные) и поведение (методы), которые будут иметь все объекты этого класса.

2. Как создать объект (экземпляр) класса?
Ответ: Объект создаётся с помощью оператора new, например: Book book1 = new Book();

3. Чем отличаются поля от свойств?
Ответ: Поля — это переменные, хранящие состояние объекта, а свойства обеспечивают доступ к полям через аксессоры get (чтение) и set (запись) и позволяют контролировать доступ.

4. Для чего нужны конструкторы?
Ответ: Конструкторы — это специальные методы, которые вызываются при создании объекта и служат для его инициализации.

5. Что такое конструктор по умолчанию? Когда он создается?
Ответ: Это конструктор без параметров. Компилятор автоматически создаёт его, если в классе не указан ни один конструктор.

6. Для чего используется ключевое слово this?
Ответ: this — это ссылка на текущий экземпляр класса. Оно используется для разрешения конфликтов имён между параметрами и полями, а также для вызова других конструкторов.

7. Какие модификаторы доступа существуют в C#? Что они означают?
Ответ: public — доступен из любого места программы; private — только внутри данного класса; protected — внутри класса и в классах-наследниках; internal — только в пределах текущей сборки.

8. Чем отличаются статические члены класса от нестатических?
Ответ: Статические члены принадлежат всему классу, хранятся в единственном экземпляре и доступны через имя класса. Нестатические члены принадлежат конкретному объекту и имеют своё значение у каждого экземпляра.

9. Как обратиться к статическому методу класса?
Ответ: Через имя класса, например: Counter.ShowCount();

10. Что такое автоматическое свойство? Как его объявить?
Ответ: Автоматическое свойство — это свойство, для которого компилятор сам создаёт скрытое поле. Объявляется так: public int Age { get; set; }
