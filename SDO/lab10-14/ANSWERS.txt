Контрольные вопросы и ответы

1. Что такое LINQ? Какие преимущества он дает разработчику?
Ответ: LINQ (Language Integrated Query) — компонент .NET для работы с данными, интегрированный в C#. Он дает единый синтаксис для разных источников данных, проверку запросов на этапе компиляции, поддержку IntelliSense и снижение объема кода.

2. В чем разница между синтаксисом запросов (query syntax) и синтаксисом методов (method syntax)? Можно ли их комбинировать?
Ответ: Синтаксис запросов напоминает SQL и использует ключевые слова from, where, select, group by, orderby. Синтаксис методов использует методы расширения (Where, Select, OrderBy) и лямбда-выражения. Эти подходы взаимозаменяемы и могут комбинироваться.

3. Что означает термин «отложенное выполнение» (deferred execution)? Приведите пример, когда запрос выполняется немедленно.
Ответ: Отложенное выполнение означает, что запрос не выполняется в момент создания переменной запроса, а только при итерации по результатам в foreach. Немедленное выполнение происходит при вызове методов, возвращающих одно значение (Count, Sum, Average), либо ToList(), ToArray().

4. Для чего используется ключевое слово var при работе с LINQ?
Ответ: Для объявления переменной запроса, когда точный тип результата сложен для явного указания, например при работе с анонимными типами; компилятор выводит тип автоматически.

5. Как работает метод Select? Чем он отличается от SelectMany?
Ответ: Select преобразует каждый элемент последовательности в новую форму. SelectMany, в отличие от него, «разворачивает» вложенные последовательности, объединяя их элементы в одну плоскую последовательность.

6. Какие существуют способы фильтрации данных в LINQ?
Ответ: С помощью метода Where (и OfType для фильтрации по типу) — как в синтаксисе методов, так и в синтаксисе запросов через where.

7. Что возвращает метод GroupBy? Как получить доступ к элементам внутри группы?
Ответ: GroupBy возвращает последовательность групп. Ключ группы доступен через свойство Key, а элементы внутри группы можно перебрать, так как группа является коллекцией (например, через foreach).

8. Какие агрегатные функции доступны в LINQ? Приведите пример использования Aggregate.
Ответ: Sum, Min, Max, Average, Count, Aggregate. Пример: numbers.Aggregate((a, b) => a + b) последовательно сворачивает элементы в одно значение (здесь — сумму).

9. В чем разница между методами First и FirstOrDefault? Когда какой следует использовать?
Ответ: First возвращает первый элемент и выбрасывает исключение, если последовательность пуста. FirstOrDefault возвращает значение по умолчанию (null или 0) при отсутствии элементов, поэтому его используют, когда пустая последовательность допустима.

10. Что такое анонимные типы и как они связаны с LINQ?
Ответ: Анонимные типы — типы без явного имени, создаваемые компилятором, например new { FullName = s.Name, Avg = s.AverageGrade }. Они часто используются в проекции LINQ (Select), когда нужен результат с новым набором свойств.
