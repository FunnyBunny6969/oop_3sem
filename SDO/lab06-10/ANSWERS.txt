Контрольные вопросы и ответы

1. Что такое обобщения (generics) в C#? Какие преимущества они предоставляют?
Ответ: Обобщения — это механизм, позволяющий создавать классы, структуры, интерфейсы, методы и делегаты, работающие с разными типами без потери строгой типизации; вместо конкретного типа используется параметр типа (например, <T>). Преимущества: безопасность типов на этапе компиляции, отсутствие упаковки (boxing) для значимых типов и повторное использование кода.

2. Чем обобщенный класс отличается от обычного класса с параметром типа object?
Ответ: При использовании object требуются приведения типов, ошибки типов выявляются только во время выполнения, а значимые типы упаковываются (boxing). Обобщённый класс обеспечивает проверку типов на этапе компиляции и отсутствие упаковки.

3. Какие типы ограничений (constraints) можно накладывать на параметры типа? Приведите примеры.
Ответ: where T : class, struct, new(), БазовыйКласс, IИнтерфейс, другой параметр типа U, unmanaged, Enum, Delegate, notnull. Например: public class AdvancedClass<T> where T : class, IComparable<T>, new().

4. Что такое ковариантность и контравариантность в обобщениях? Для каких типов они поддерживаются?
Ответ: Ковариантность (out) позволяет вместо производного типа использовать базовый (например, IEnumerable<out T>), контравариантность (in) — наоборот (например, IComparer<in T>, Action<in T>). Они поддерживаются только для обобщённых интерфейсов и делегатов, но не для классов.

5. Можно ли использовать обобщения со значимыми типами (struct) и ссылочными типами (class)? В чем разница?
Ответ: Да, обобщения работают и со значимыми, и со ссылочными типами. Для значимых типов создаётся отдельная специализированная версия кода без упаковки, а для ссылочных используется общая реализация, где параметр типа хранится как ссылка.

6. Что произойдет, если попытаться создать экземпляр обобщенного класса без указания параметра типа?
Ответ: Компилятор выдаст ошибку: параметр типа должен быть указан явно или выведен из контекста, например GenericClass<int>, а не просто new GenericClass().

7. Как работает механизм стирания типов (type erasure) в C#? Сохраняется ли информация о типе во время выполнения?
Ответ: В C# нет стирания типов в стиле Java: обобщения реализованы в CLR, и информация о типе сохраняется во время выполнения. Для разных значимых типов создаются отдельные версии кода, а тип доступен через typeof(T).

8. Можно ли создать обобщенный конструктор в необобщенном классе?
Ответ: Нет, конструктор не может иметь собственных параметров типа. Обобщённым может быть только класс, а его конструктор использует параметры типа этого класса.

9. Что такое обобщенные методы и чем они отличаются от обобщенных классов?
Ответ: Обобщённый метод объявляет собственный параметр типа, например void Swap<T>(ref T a, ref T b), и может находиться в обычном или обобщённом классе. Отличие в том, что параметр типа задаётся при вызове конкретного метода, а не при создании объекта класса.

10. Как использовать ключевое слово default с обобщенными типами?
Ответ: default(T) возвращает значение по умолчанию для типа T: null для ссылочных и Nullable-типов и нулевое значение для значимых типов. Например: T item = default(T);
