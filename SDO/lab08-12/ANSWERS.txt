Контрольные вопросы и ответы

1. Что такое лямбда-выражение? Какой оператор используется для его записи?
Ответ: Лямбда-выражение — это анонимная функция, блок кода, который можно передать как аргумент или сохранить для последующего выполнения. Для его записи используется оператор => (читается «переходит в»).

2. Какие существуют формы записи лямбда-выражений (с одним параметром, с несколькими, без параметров, с блоком операторов)?
Ответ: x => x * x (один параметр), (x, y) => x + y (несколько параметров), () => DateTime.Now (без параметров), (x, y) => { int sum = x + y; return sum; } (с блоком операторов). Типы параметров можно указывать явно или опускать.

3. Что такое замыкание (closure) в лямбда-выражениях? Приведите пример.
Ответ: Замыкание — это захват лямбда-выражением переменных из внешнего контекста. Пример: int factor = 10; Func<int, int> multiply = x => x * factor; — переменная factor захватывается, и её изменение влияет на результат.

4. Чем отличаются делегаты Action, Func и Predicate? В каких случаях какой делегат использовать?
Ответ: Action возвращает void и используется для выполнения действия; Func возвращает значение TResult и используется для вычисления результата; Predicate принимает один параметр и возвращает bool и используется для проверки условия.

5. Как с помощью лямбда-выражения и метода Array.FindAll отфильтровать массив?
Ответ: Например: int[] even = Array.FindAll(numbers, x => x % 2 == 0); — метод возвращает новый массив, содержащий все элементы, удовлетворяющие условию.

6. Как с помощью лямбда-выражения и метода Array.ConvertAll преобразовать массив?
Ответ: Например: int[] squares = Array.ConvertAll(numbers, x => x * x); — метод создаёт новый массив, применяя функцию преобразования к каждому элементу.

7. Как с помощью лямбда-выражения и метода Array.Sort задать пользовательский порядок сортировки?
Ответ: Например: Array.Sort(numbers, (a, b) => b.CompareTo(a)); — лямбда-выражение задаёт сравнение двух элементов и тем самым определяет порядок сортировки.

8. Для чего используются методы Array.Exists и Array.TrueForAll? В чем их различие?
Ответ: Array.Exists проверяет, есть ли в массиве хотя бы один элемент, удовлетворяющий условию. Array.TrueForAll проверяет, удовлетворяют ли условию все элементы массива.

9. Как с помощью лямбда-выражения найти первый или последний элемент, удовлетворяющий условию?
Ответ: Первый элемент находит Array.Find(array, x => условие), последний — Array.FindLast(array, x => условие). Для индексов используются Array.FindIndex и Array.FindLastIndex.

10. Можно ли в лямбда-выражении использовать обработку исключений? Если да, то как?
Ответ: Да, если лямбда-выражение записано с блоком операторов, внутри можно использовать try-catch-finally так же, как в обычном методе: x => { try { ... } catch (Exception ex) { ... } }.

11. Какие ограничения есть у лямбда-выражений?
Ответ: Они не могут содержать goto, break, continue вне блока, не могут использовать ref и out параметры, не могут быть обобщёнными и не могут применяться в небезопасном коде.

12. В чем преимущества использования лямбда-выражений перед обычными методами?
Ответ: Краткость, читаемость, локализация логики прямо в месте использования и доступ к внешнему контексту через замыкания без лишних параметров.
