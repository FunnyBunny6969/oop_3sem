

## 1. Что такое .NET Framework и из чего он состоит?

**.NET Framework** — это платформа для разработки и выполнения приложений под Windows.

**Состоит из двух основных частей:**
- **CLR (Common Language Runtime)** — среда выполнения управляемого кода.
- **FCL (Framework Class Library)** — огромная библиотека готовых классов (работа с файлами, сетью, БД, GUI и т.д.).

---

## 2. Что такое CLR, FCL/BCL, CLI, IL?

| Термин | Расшифровка | Что это |
|--------|-------------|---------|
| **CLR** | Common Language Runtime | Среда выполнения .NET-приложений. Управляет памятью, безопасностью, JIT-компиляцией. |
| **FCL** | Framework Class Library | Полная библиотека классов .NET Framework. |
| **BCL** | Base Class Library | Ядро FCL — базовые типы (строки, коллекции, ввод/вывод). |
| **CLI** | Common Language Infrastructure | Стандарт, описывающий среду выполнения .NET (ECMA-335). |
| **IL** | Intermediate Language | Промежуточный код, в который компилируется исходный код (C#, VB.NET и др.). Затем JIT компилирует IL в машинный код. |

---

## 3. Пояснить работу JIT-компилятора?

**JIT (Just-In-Time)** компилятор:
1. Компилирует **IL** в **машинный код** непосредственно перед выполнением метода.
2. Результат кэшируется — при повторном вызове метода машинный код используется повторно.
3. Работает по требованию (только те методы, которые реально вызываются).

**Плюсы:** оптимизация под конкретную архитектуру.
**Минусы:** небольшая задержка при первом вызове метода.

---

## 4. Что такое CTS (Common Type System)?

**CTS** — это часть .NET, которая определяет:
- **Общие типы данных** (int, string, bool и т.д.)
- **Правила взаимодействия** между типами (наследование, видимость, методы).

Благодаря CTS код на C# может вызывать код на VB.NET — оба используют одну и ту же систему типов.

## 6. Что находится в mscorlib.dll?

**mscorlib.dll** — основная библиотека .NET. Содержит:
- `System.Object`, `System.Int32`, `System.String` и другие базовые типы.
- Коллекции (`System.Collections`).
- Исключения (`System.Exception`).
- Базовые классы для работы с памятью, потоками, сериализацией.

## 7. Что такое «сборка»? Из чего состоит сборка .NET?

**Сборка (Assembly)** — единица развертывания и версионирования .NET приложений.

**Состав сборки:**
- **Манифест** (информация о сборке)
- **IL-код** (исполняемый код)
- **Метаданные** (информация о типах)
- **Ресурсы** (изображения, строки и т.д.)

---

## 8. Какие виды сборок существуют?

| Тип | Описание |
|-----|----------|
| **Исполняемые (.exe)** | Содержат точку входа (`Main`) |
| **Библиотеки (.dll)** | Код для использования другими приложениями |
| **Сильные (Strong-named)** | Имеют цифровую подпись для уникальности |
| **Однофайловые / Многофайловые** | Один или несколько файлов |
| **Частные / Общие (GAC)** | Доступны только в папке приложения или глобально |

---

## 9. Что такое assembly manifest?

**Манифест** — это метаданные внутри сборки, которые содержат:
- **Имя** и версию сборки.
- **Культуру** (язык).
- **Список зависимостей** (какие сборки требуются).
- **Список экспортируемых типов**.

---

## 10. Что такое GAC?

**GAC (Global Assembly Cache)** — глобальный кэш сборок в Windows. Хранит сборки, которые могут использоваться любыми приложениями на компьютере. Обычно это системные сборки (.NET Framework). Несколько версий одной сборки могут существовать одновременно.

---

## 11. Чем managed code отличается от unmanaged code?

| | Managed (управляемый) | Unmanaged (неуправляемый) |
|---|---|---|
| **Управление памятью** | CLR (сборщик мусора) | Программист (malloc/free) |
| **Безопасность** | Высокая (проверка типов) | Низкая (уязвимости) |
| **Среда** | .NET CLR | WinAPI, C/C++, COM |
| **Пример** | C#, VB.NET | C++ без /clr, старый C |

## 12. Как и для чего определен метод Main?

**`Main`** — точка входа в приложение.

```csharp
static void Main()                 // без параметров
static void Main(string[] args)    // с аргументами командной строки
static int Main()                  // возвращает код завершения
static int Main(string[] args)     // с параметрами и кодом завершения
```

**Модификаторы:** `static`, может быть `void` или `int`. Может быть `async` (с `Task`).

## 14. Как связаны между собой сборки и пространства имен?

- **Пространства имен** — логическая группировка типов (не зависят от физического расположения).
- **Сборки** — физическая группировка кода (файлы .dll/.exe).
- Одна сборка может содержать несколько пространств имен.
- Одно пространство имен может быть разбросано по нескольким сборкам.

## 16. Что такое ссылочные типы? Какие типы относятся к ним?

**Ссылочные типы** хранят ссылку на данные (в куче), а не сами данные.

**Примеры:**
- `string`
- `object`
- Классы (`class`)
- Интерфейсы (`interface`)
- Делегаты (`delegate`)
- Массивы (`array`) — да, они ссылочные!

---

## 17. Какие типы относятся к типам-значениям?

**Типы-значения** хранят данные напрямую (в стеке или внутри объекта).

**Примеры:**
- Все числовые: `int`, `double`, `byte`...
- `bool`, `char`
- Перечисления (`enum`)
- Структуры (`struct`)
- `Nullable<T>` (`int?`)

---

## 18. В чем отличие между ссылочными и значимыми типами данных?

| | **Значимые (Value types)** | **Ссылочные (Reference types)** |
|---|---|---|
| **Хранение** | В стеке (или внутри объекта) | В куче |
| **Передача** | Копируется значение | Копируется ссылка |
| **Сборка мусора** | Не участвует | Участвует |
| **Наследование** | Не могут наследовать (кроме интерфейсов) | Могут наследовать |
| **Пример** | `int`, `struct`, `enum` | `class`, `string`, `array` |

## 19. Что такое упаковка и распаковка значимых типов?

| | Что происходит | Пример |
|---|---|---|
| **Boxing (упаковка)** | Значимый тип → `object` | `object o = 42;` |
| **Unboxing (распаковка)** | `object` → значимый тип | `int i = (int)o;` |

**Проблема:** снижение производительности (выделение памяти в куче). Старайтесь избегать в циклах.

## 20. В чем заключается разница между int и System.Int32? double и System.Double и т.д.?

**Никакой разницы.** `int` — это псевдоним (alias) для `System.Int32`. Компилятор заменяет их автоматически. Одно и то же.

**Все алиасы:**
- `int` = `System.Int32`
- `double` = `System.Double`
- `string` = `System.String`
- `object` = `System.Object`

## 21. Для чего используется тип dynamic?

**`dynamic`** — тип для работы с объектами, где проверка типов выполняется в **runtime**, а не в compile-time.

**Используется:**
- Для COM-взаимодействия (например, Excel).
- Для работы с динамическими языками (Python, JavaScript).
- Для работы с JSON без классов.

```csharp
dynamic d = "Hello";
d = 42;              // Нет ошибки компиляции
d.SomeMethod();      // Ошибка будет только в runtime
```

## 22. В чем заключается главное отличие между var и dynamic?

| | **var** | **dynamic** |
|---|---|---|
| **Тип определяется** | На этапе компиляции | На этапе выполнения (runtime) |
| **Проверка типов** | Статическая (compile-time) | Динамическая (runtime) |
| **IntelliSense** | Работает | Не работает |
| **Изменение типа** | Нельзя изменить | Можно менять |
| **Пример** | `var x = 5; // int` | `dynamic y = 5; y = "text";` |

## 23. Что такое неявно типизированная переменная?

Переменная, объявленная с ключевым словом **`var`**, тип которой определяется компилятором на основе значения.

```csharp
var x = 10;            // x — int
var s = "Hello";       // s — string
var arr = new int[5];  // arr — int[]
```

Тип задается **один раз** при объявлении и не может измениться.

## 24. Для чего используют Nullable тип?

**`Nullable<T>`** (или `T?`) позволяет значимым типам (value types) принимать значение `null`.

```csharp
int? age = null;        // Теперь int может быть null
bool? isActive = null;

if (age.HasValue) { ... }
int realAge = age ?? 0; // оператор объединения с null
```

Используется:
- В базах данных (поля могут быть NULL).
- Для флагов и необязательных значений.

## 31. Поясните явные преобразования переменных с помощью команд Convert.

**`Convert`** — статический класс для безопасного преобразования типов.

```csharp
int i = Convert.ToInt32("123");      // Строка → int
double d = Convert.ToDouble("45.67"); // Строка → double
bool b = Convert.ToBoolean("True");   // Строка → bool
string s = Convert.ToString(42);      // int → string
```

**Отличие от приведения (`(int)x`):**
- `Convert` работает с разными типами (строки, даты).
- `Convert` может выбрасывать `FormatException` и `OverflowException`.

## 36. Что такое кортеж? Для чего и как он используется?

**Кортеж (Tuple)** — легкая структура для группировки нескольких значений без создания отдельного класса.

**Использование:**
- Возврат нескольких значений из метода.

var tuple1 = Tuple.Create(42, "Hello");

```csharp
var (id, name) = person;   // deconstruction
```

## 37. Что такое локальная функция? Какова область ее видимости?

**Локальная функция** — функция, определенная внутри другой функции.

```csharp
void Main()
{
    int Square(int x) => x * x;
    Console.WriteLine(Square(5)); // 25
}
```

**Особенности:**
- Видима **только** внутри метода, где объявлена.
- Может использовать локальные переменные родительского метода (замыкания).
- Может быть `static` (не захватывает контекст).
- Хороша для вспомогательной логики внутри метода.

## 38. В чем разница между кодом, заключенным в блок checked и кодом, заключенным в блок unchecked?

| | **checked** | **unchecked** |
|---|---|---|
| **Переполнение** | Вызывает `OverflowException` | Игнорирует, обрезает значение |
| **Безопасность** | Безопасный | Небезопасный, но быстрее |
| **Использование** | Когда переполнение критично | Когда переполнение допустимо |

```csharp
checked {
    int x = int.MaxValue + 1;  // OverflowException
}

unchecked {
    int x = int.MaxValue + 1;  // x = -2147483648 (обертка)
}
```

## 39. Какой контекст (checked/unchecked) применяется по умолчанию? Как можно переопределить это поведение?

- **По умолчанию:** `unchecked` (для арифметики с числами).
- **Исключение:** `checked` для констант на этапе компиляции.

**Переопределение:**
1. **Локально:** через блоки `checked { }` / `unchecked { }`.
2. **Глобально:** в настройках проекта (свойства → сборка → "Проверять арифметическое переполнение").
3. **Через компилятор:** ключ `/checked+` или `/checked-`.

## 40. Для чего используется ключевое слово fixed? Каковы особенности его использования?

**`fixed`** используется в **небезопасном коде** (`unsafe`) для:
1. Фиксации управляемого объекта в памяти (чтобы сборщик мусора не переместил его).
2. Получения указателя на него.

```csharp
unsafe {
    int[] arr = new int[10];
    fixed (int* ptr = arr) {
        *ptr = 42;   // работа с указателем
    }
}
```

**Особенности:**
- Только в `unsafe` контексте.
- Фиксирует объект на время блока.
- Используется для взаимодействия с неуправляемым кодом (C/C++).
- Снижает производительность из-за блокировки сборки мусора.
